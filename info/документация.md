**Основные возможности**

Проверка DNS – получение A-записей (IPv4) с измерением времени ответа (фактически задержка DNS).



Проверка HTTP/HTTPS – отправка GET-запроса, проверка статус-кода (2xx/3xx считаются успешными).



Общий статус – домен считается доступным только если успешны и DNS, и HTTP.



Красивая таблица – с использованием rich.Table; цветовое кодирование (зелёный – OK, красный – ошибка, жёлтый – предупреждение).



Логирование – при включении все итерации дописываются в текстовый файл monitoring\_temp.txt, который по окончании работы перемещается в папку history/ с меткой времени.



Ротация логов – автоматическое удаление файлов старше 30 дней и ограничение общего числа файлов в history/ до 50.



Гибкая настройка списка доменов – через файл domains.txt (по одному домену на строку, строки с # игнорируются). Если файл отсутствует – используется встроенный список.



Интерактивный выбор логирования – при запуске скрипт спрашивает, нужно ли сохранять результаты в файл.



Остановка по Ctrl+C – корректное завершение с сохранением лога и выводом итоговой статистики.









**Краткое описание функций (по коду)**

load\_domains\_from\_file(filename) - Загружает список доменов из текстового файла (по одному на строку). Если файла нет или он пуст – возвращает встроенный список DEFAULT\_DOMAINS.



check\_dns(domain) - Выполняет DNS-резолвинг (A-запись). Возвращает (успех, сообщение с IP или ошибкой).



check\_http(domain) - Пытается выполнить GET-запрос по HTTPS, затем по HTTP. Возвращает (успех, сообщение, статус-код).



check\_overall(dns\_ok, http\_ok) - Определяет общий статус доступности домена.



run\_checks(domains) - Последовательно проверяет все домены из списка и возвращает список словарей с результатами.



build\_status\_table(results) - Создаёт объект rich.Table с цветовым оформлением.



log\_results\_to\_file(filepath, iteration, results) - Дописывает в лог-файл информацию об итерации и результатах.



archive\_log(temp\_filepath) - Перемещает временный лог в папку history/, добавляя к имени временную метку.



rotate\_logs(history\_dir, max\_files, max\_days) - Удаляет файлы старше max\_days дней, затем при превышении max\_files удаляет самые старые.



ask\_for\_logging() - Запрашивает у пользователя необходимость логирования (y/N).



main() - Основной цикл: загрузка доменов, запрос логирования, бесконечная проверка с заданным интервалом, обработка Ctrl+C.







**примечания**

DNS-проверка использует системный резолвер (обычно до 3 секунд таймаут).



HTTP-проверка имеет таймаут 5 секунд.



Интервал между итерациями – 10 секунд (можно изменить в переменной CHECK\_INTERVAL).



При отключённом логировании временный файл не создаётся.



Папка history/ создаётся автоматически при первом сохранении лога.











**При остановке лог (если включён) автоматически сохраняется в папку history/ с именем monitoring\_ГГГГММДД\_ЧЧММСС.txt.**
