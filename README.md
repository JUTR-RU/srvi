Скрипт выполняет периодическую проверку DNS-разрешения и HTTP-доступности заданного списка доменов. 
Результаты отображаются в цветной таблице с использованием библиотеки rich. 
Поддерживается опциональное логирование результатов в файл с автоматической ротацией (удаление старых логов, ограничение количества файлов).

Для запуска откройте bat-файл run_monitor

Для изменения списка проверяемых доменов откройте domains и с новой строки вводите их(также можете удалять). 
Если данного файла не будет в папке со скриптом, будет использоват базовый список доменов.
